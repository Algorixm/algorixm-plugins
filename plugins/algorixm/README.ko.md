# Algorixm

**대화에서 영상을 만들고, Draft에서 이어서 편집해요.**

Claude Code와 Codex에서 Draft 영상의 모션 그래픽·장면·자막을 만들고 수정할 수 있어요. 결과는 같은 프로젝트에 저장돼서 브라우저 편집기에서 바로 이어서 다듬을 수 있어요. Algorixm의 데이터베이스, 블로그·링크 페이지, 화이트보드, 자동화와 SNS 작업도 함께 다뤄요.

## 이렇게 요청해 보세요

- “제품 소개용 15초 영상을 Draft에 만들고, 편집할 수 있는 프로젝트 링크를 줘.”
- “가장 최근 영상의 장면 구성을 먼저 보여줘. 아직 수정하지 마.”
- “첫 장면 제목만 바꾸고, 길이와 나머지 디자인은 유지해 줘.”
- “콘텐츠 캘린더를 읽고 다음 게시물 아이디어 세 개를 제안해 줘. 게시하지는 마.”

## 설치와 로그인

[저장소의 설치 안내](https://github.com/Algorixm/algorixm-plugins#readme)에 따라 플러그인을 설치한 뒤 새 대화를 열어요. Claude Code에서는 `/mcp`에서 Algorixm에 로그인해요. 연결 주소는 `https://algorixm.com/mcp`예요.

기존 Algorixm 계정이 필요해요. 로그인한 계정이 접근할 수 있는 스페이스를 현재 역할 범위에서 다루므로, 변경할 스페이스를 먼저 정해요. 생성·미디어·렌더링에는 계정 권한과 기존 크레딧이 필요할 수 있어요. SNS 작업은 Algorixm에서 미리 연결한 채널을 사용해요.

플러그인은 로컬 서버나 실행용 패키지를 설치하지 않아요. 시작 훅을 실행하거나 Claude Code·Codex의 승인 설정을 바꾸지 않고, 각 호스트의 권한을 따라요.

## 저장되는 내용과 실행 범위

요청한 작업의 도구 입력과 필요한 콘텐츠를 Algorixm 서버로 보내고, 도구 결과를 AI 호스트에 돌려줘요. 영상 프로젝트·업로드 미디어·데이터베이스 행·자동화 상태는 Algorixm 계정에 저장돼요. 생성 작업에는 설정된 AI·미디어 제공자가 사용될 수 있고, 승인한 SNS 게시물은 연결한 서비스로 전송돼요. 플러그인이 전체 대화나 관련 없는 로컬 파일을 따로 수집하지는 않아요.

데이터 처리와 보유 기간은 [개인정보 처리방침](https://algorixm.com/privacy)을 따라요. AI 호스트에서 연결을 해제하면 이후 도구 접근이 중단되지만, 이미 저장된 프로젝트가 삭제되지는 않아요. 삭제는 제품 화면이나 [문의](https://algorixm.com/contact)를 이용해요.

영상 제작 요청만으로 SNS에 공개 게시하지 않아요. 게시·반복 실행·삭제는 사용자가 요청한 범위에서 진행해요. 비밀 값과 SNS 인증 토큰 조회, 채널 연결, 크레딧 구매는 지원하지 않아요. 권한이나 크레딧이 부족하면 해당 제한을 알려줘요.

문제가 생기면 오류와 프로젝트·실행 ID를 함께 알려주세요. 비밀번호·토큰·인증 코드는 대화나 문의 내용에 넣지 않아도 돼요.
