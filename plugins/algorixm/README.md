# Algorixm

Draft에서 영상을 기획·제작·편집·내보내고, Algorixm의 데이터베이스, 블로그·링크 페이지, 화이트보드, 자동화, 플레이북, SNS 게시를 Claude나 Codex 대화로 처리합니다. `https://algorixm.com/mcp`에 연결하며, 처음 쓸 때 Algorixm 계정으로 로그인합니다. 작업은 내 비즈니스 역할 권한과 크레딧 안에서만 실행되고, 유료 작업은 먼저 예상 크레딧을 확인합니다.
